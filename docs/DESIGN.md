# Design

视觉系统（2026-09-17 第三版，外层 [#64](https://github.com/zephyr4123/TJU-AI4Science/issues/64)）。第一版仪表盘被否，第二版一页纸白底琥珀，这一版给页面一个性格：实验记录本。

## Scene

给不写代码的研究者用的科研工作台。页面头号任务一句话：现在做到哪一步、在等谁、数字可不可信。世界观来自实验记录本和评分脚本——账本、基线、统计门、验证、需求的确认与产出的确认两处人的动作。视觉从这儿长，不从 SaaS 模板长。

## Color strategy

五个颜色都是信息，不是装饰。一眼分得出三种状态：助理在跑（靛）、等你（琥珀）、可信（铜绿）。

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--background` 纸 | `#F5F6F8` | `#171A20` | 工作面，冷白不是奶油色 |
| `--foreground` 墨 | `#1C2230` | `#E6E8EE` | 正文与标题，蓝黑墨水 |
| `--primary` 靛 | `#2F4BC9` | `#8FA3F5` | 助理在动、可点的东西、流程线、发送键 |
| `--ok` 铜绿 | `#1F7A6D` | `#5FC2B0` | 只给「验证通过、可信」 |
| `--wait` 琥珀 | `#B8741A` | `#E2A751` | 只给「待确认」：需求、流程里断点前的产出 |
| `--muted-foreground` | `#5B6270` | `#9AA1AE` | 次要文字（对纸面 ≥ 4.5:1） |
| `--card` | `#FFFFFF` | `#1E222A` | 顶栏、看板上填实的卡、输入框 |

深色跟系统偏好，页眉右边的开关可以拨（记在本机 localStorage，`lib/theme.ts` 写 `<html data-theme>`，画布类组件经 `themechange` 重读 tokens）。`--bad` 只给出错，配文字与图标一起出现，不单靠颜色。

## Typography

两族，分工清楚：

- **思源宋体（Noto Serif SC Variable）**：只给页面上的一句话标题（`.t-lede`：欢迎语、需求的课题名）、看板上阶段与产出的标题（`.t-step`）、Markdown 里的标题、顶栏名字。助理的回复按普通 Markdown 排，不拎结论（主人：别限得这么死，让它自己用 Markdown 发挥）。期刊味，和实验记录本对味。
- **IBM Plex Sans Variable + 系统中文**：正文、界面、数字（全局 `tabular-nums`）。命令与文件名用 IBM Plex Mono，因为它们真是命令。

| 角色 | 尺寸 / 行高 / 字重 |
|---|---|
| 一句话标题 `.t-lede` | 1.25rem / 1.45 / 600 宋体 |
| 步骤标题 `.t-step` | 1rem / 1.4 / 600 宋体 |
| 大数字 `.t-big` | 1.75rem / 1 / 500，等宽数字 |
| 正文 `.t-body` | 0.9375rem / 1.65 / 400，行长 ≤ 68ch |
| 标签 `.t-label` | 0.8125rem / 1.4，`--muted-foreground` |

不做的：全大写小标签、中点串元信息（写成一句话）、给标题里某个词单独上色。

## Layout

最左一条**地方栏**，只剩三个键（外层 [#136](https://github.com/zephyr4123/TJU-AI4Science/issues/136)，主人 2026-09-22：侧边栏列项目很鸡肋）：宽屏常驻 4.5rem——顶上一枚玻璃标记，底下「首页」「编辑台」两个键是两个平行的世界（纲领 P-15 P-16），最底下「设置」（P-25，归人、全局一份，旁一个琥珀点，有一项自检没过才亮）；每个键都带字（主人：没字用户不知道是啥）。项目不在栏上列，首页就是项目墙。窄屏收进页眉左端的玻璃标记，点开一张清单，同样三行。页眉只属于当前地方：项目页与工作区页底下铺项目的封面糊成一抹颜色（换项目就换色），工作区页写「‹ 项目名  工作区 ▾」；首页与门口那一屏宽屏没有页眉（画面铺满），窄屏留一条放入口。页面先认项目（一个项目一位助理，工作区是它的工位）：

- **首页 = 项目墙**：一格一个项目（reactbits MagicBento 改装，`components/reactbits/MagicBento.tsx`：鼠标离哪格近哪格的边缘亮一圈、格里跟着一团淡光，星星粒子、磁吸、倾斜都不要），字在前——宋体项目名、目标一句、底下一行事实「N 个工作区 · 创建于几月几日 · 运行中 K」；封面压暗铺在格子底下（主人：图可以作背景，信息必须陈列出来，图不能是主角），新的在前。右上角「新建项目」。一个项目都没有：一句「还没有项目」加一枚玻璃键「新建项目」（与「打开对话」同一种 SpecularButton）。
- **门口那一屏**（起项目）：一句「要研究什么？」、一只和对话输入框同款的玻璃输入框，写下课题回车即建，第二行「目标，可不填」进 project.md 标题下面那段；文件夹名从标题里推（拉丁词小写连字符相连，没有就按日期，重名加 -2），是内部 id，不显示也不让人填（外层 [#109](https://github.com/zephyr4123/TJU-AI4Science/issues/109)）；底下铺一段循环视频：浅色云雾、深色光线汇聚，纱幕压到字能读。第一个工作区不在这里起——进了项目跟助理说，它去开；或按项目页的「新建」。
- **项目页**（主人 2026-09-22：对话入口从右边的板搬到正中间，一个项目只有一位助理，入口顺理成章只有一个，像 Claude 的首页）：底下铺项目的封面（mist 纱幕），正中一列 44rem——宋体大项目名、目标一句、一只玻璃输入框（placeholder「要做什么？」，上面「助理 / 模型 / 思考」三枚片），打的第一句话就开始对话：输入框**竖直下沉到底**（motion 的 layoutId，两边的盒子都紧贴玻璃框、同宽 44rem——盒子比玻璃框宽会斜着走；减少动效直接出现），正文淡入接在上面，这一轮从按下回车起就在屏上（主人：不要闪一下再切过去；`chat/useConversation`：先开一段再发，跑完先重读落盘的再撤屏上的，按轮次去重），页眉「‹ 项目名」+ 对话标题 + 花费 + 「对话 · N」；输入框底下是**工作区清单**，一行一个（shadcn item 的形状）：reactbits StatusMark 改装的状态符（空心虚线环 / 转圈 / 勾 / 叉）、宋体名字、两句小字（第一条流程走到第几步、产出几次）、右端状态一个词（需求未确认 琥珀 / 运行中 靛 / 待确认 琥珀 / 进行中 靛 / 完成 铜绿 / 尚未选定流程 素 / 流程文件有误 红；`project/derive.ts`），点一行进工作区页；「新建」在清单那一行，点了才在清单顶上展开表单（课题一句、学科片、回车即建，建好直接进那个工作区），加完收回去；最底下「对话 · N」是过去对话的抽屉，挑一段也切成整屏的对话。右上角「…」里是删除项目。
- **工作区页**（改实例）：页眉「‹ 项目名」回项目页，工作区名是一枚下拉片（GlideSelect，列兄弟工作区，直接换工位），右边「看板 / 文件」两个镜头与「…」（删除工作区）。**看板铺满**、对话是右边一块悬在雾景上的板——还是项目的那一段，边看看板边说话（`chat/ChatPanel.tsx`，编辑台用同一块但另一种摆法（主人 2026-09-23：既然是浮窗，底下就别再分栏，拆开就拆开）：30rem，四周留 12px、圆角 2xl、长而软的投影 + 一圈 6% 的 ring，和文件镜头的内容面同一种材料，雾景铺满整行、板悬在上面（背景不能到板的左边就断）——主人 2026-09-19：`border-l` 一刀切出来的全高一列像拼上去的；工作区页是 beside（板占一列、看板在左，看板不能被盖住），编辑台是 float（画布铺满整行、板绝对定位浮在右边、关了淡出，画布右上角的键、底下的判词与取景按 `useChatInset()` 让开板的宽度，「能力」镜头那一面同样在右边留出板的宽度、列自动折到下面）；默认开着，人关了剩右下角一个带字的玻璃键「打开对话」），看板按 `requirement.lock` 在不在分两个状态（纲领 P-19，外层 [#104](https://github.com/zephyr4123/TJU-AI4Science/issues/104) [#107](https://github.com/zephyr4123/TJU-AI4Science/issues/107)）：
  - **没确认**：需求文档就是页面。宋体课题名、右边「需求 · 未确认 · 填了几节」，模板开头那段说明淡字，下面按二级标题两列一格一节（填了的是 SpotlightCard，正文 markdown；「待填」的虚线框灰字），最底下一个「确认」（StarBorder，署名记在本机）。页面只渲染不编辑：改需求跟右边的助理说，它改文件，页面每轮对话结束重读。
  - **确认了**：需求收成顶部一条（课题名、v 几、谁、何时；点开侧滑看全文），助理又改了这条变琥珀、写「N 行改动 · 待确认」，侧滑里是上一版对现在的行级 diff（加的绿、删的红）与「确认」下一版。下面**一条流程一张表**（主人 2026-09-19：七个格子加一条流程两套东西叠着看不明白，大胆做减法；语言用正式直白的词，不用「签」「没成」这类口语）：题头是流程的标题，右上角一句话说在等谁（下一步：实验 · 助理 / 待确认：设计 1 / 运行中：实验 2 / 完成 / 流程文件有误）；「运行中」旁边一枚素色「停止」，第一下拉开保险（变红、写「确认停止」）、第二下才停（`POST …/jobs/<jid>/stop`，署名沿用确认键的名字；外层 #115）。横向是流程经过的阶段，有什么阶段就几列（11.5rem 一列，横向可滚）：列头阶段图标 + 宋体阶段名，底下两行小字按能力的 tag 分（主人 2026-09-22：一眼看出哪个是步骤、哪个是 skill，行名就是 tag）——「步骤」一行是点名的（靛色小片）或没点名时这个阶段能用的（素色小片），一个没有写「无」；「skill」一行只在这一格挂了 skill 时出现（描边小片）；纵向是这一列跑过的每一次产出，一张一个：编号 + 一个词（运行中 靛 / 失败 红 / 待确认 琥珀 / 已确认 铜绿 / 完成 素）。下一步那一列靛色边框、里面一张虚线「下一步」；作业在跑是「运行中」带呼吸点；没到的列虚线淡、占一张空框。断点是两列之间一道竖线：签名的笔（待确认琥珀实心）或 ✓（已确认铜绿），没到是灰；线底下两三个字（确认事项的第一段，最多六个字），全句悬停。不在任何流程里的产出只在最底下一行「其它」；还没取流程只有一句「尚未选定流程」。产出点开**侧滑**：记录（来源写产它的能力的名、状态、输入是可点的「设计 · 1」、流程写标题与第几项、需求第几版、时间、参数写描述符的 label；P-21 内部名不上屏）、目录里的文件（小文本直接渲染，二进制只给名字）、这次产出的作业、确认（流程在这儿等你确认就带一句提示；确认过的显示谁何时、目录改了就写「之后有改动」）。有作业在跑时每 10 秒重拉一次，别的对话起的作业跑完这边才看得见。**文件镜头**（主人 2026-09-19：每个工作区要能看见盘上实际的目录，之后每个工作区单独 Git 管理，看不见代码不 make sense；不是地方栏上第三个地方，是同一个工作区的另一个镜头，外层 [#111](https://github.com/zephyr4123/TJU-AI4Science/issues/111)）：页眉右侧一枚「看板 / 文件」分段开关，对话列两边都在。第二版（主人：第一版两个平面一根竖线一条横线，全是平方块没有层次；「纸墨」隐喻否掉——另一种 AI 味）：**去框，只留一个面**。左边 17rem 的树不要底色不要边框，直接印在雾景上，它是索引不是面板；右边内容区是一块抬起的板（`bg-card`、长而软的投影、圆角 2xl、一圈 6% 的 ring，四周留 12px），两者之间不用线分；对话那块板在它右边，中间一条雾景。树是大纲不是文件管理器：每一级一根浅灰缩进导线（不上色——主人：蓝线太丑）；阶段目录写宋体阶段名 + 阶段图标，行距统一不分组（主人：分组的空行看着像没对齐）；产出那一层编号，状态词右对齐成一列（运行中 靛带呼吸点 / 失败 红 / 已确认 铜绿带 ✓ / 完成 素），被引用或已确认的再一把小锁；选中行是左缘 2px 靛条 + 加粗，不是填充色块；`.ai4sci/` 灰显垫底；根一层按工作区骨架排；产出那一层第一下点正文是选中看记录并展开，已选中再点就开合，折角单独可点；一层一层懒加载，子目录加载不画骨架，空目录一行「空」。内容区头部是「位置」：面包屑写平台语义（⚗ 设计 › 1 · 已确认 › harness，每段可点回上一级），底下文件名 mono 大字 + 大小与行数，右侧「在看板打开」（属于产出的文件）；没有「下载」——文件本来就在盘上（主人）。正文按种类：代码高亮（highlight.js 只装 python / yaml / json / bash / ini 五种，配色只用站内三色：关键字靛、字符串铜绿、数字琥珀、注释灰）、行号在一根细竖线左侧钉住、不折行横向滚；markdown 排版；csv / tsv 成表（数字列右对齐等宽，最多 200 行）；图片居中放在中性底上；超过 200 KB 只显示开头、二进制只说一句不显示。选中产出那一层，右边是位置 + 侧滑那份记录与确认。进来先看 `requirement.md`；从看板侧滑「打开目录」过来就展开到那次产出并选中。只看不改；Git 状态先不画。画面全是风景（主人：别用玻璃瓶、实验室味的图）：门口那一屏的视频与欢迎屏的雾山放胆，对话与看板底下的只是氛围（`.veil-mist` 压七成）。
- **对话抽屉**：入口是一枚带字的圆角按钮「对话 · N」（hover 扫过一道淡靛光）——项目页在清单底下、整屏对话与工作区页在对话那一行头上；顶上是项目的封面（编辑台是库的横幅），字站在脚下压成纸色的那一段；清单逐条浮现，当前那段的气泡图标填实。

## 文案

词表只有一份，在外层纲领 workflow §5 界面适配（P-21，外层 [#112](https://github.com/zephyr4123/TJU-AI4Science/issues/112)），这里不抄：一个概念一个词，没进词表的词不上屏。页面上的字按四条走：

- **标签是名词，按钮是动词，句子只进解释层。** 标签、列名、状态词、节点名两到四字名词；按钮两字动词（保存、覆盖、排列、确认）；解释性文字只在 hover、空态、展开层，一句为限，工程语言不口语（不写「签了」「没成」「在跑」「干什么」这类）。
- **机器的名字不上屏。** 翻译在后端做，前端只显示后端给的中文：

  | 机器的名字 | 页面上 | 来源 |
  |---|---|---|
  | 能力名 `auto-research` | AutoResearch | 描述符 `title`；skill 的名就是它的名字（pdf） |
  | 参数名 `max_iters` | 最多轮数 | 描述符参数 `label`，`help` 做 hover |
  | 产出 id `design/1` | 设计 · 1 | 阶段名 + 编号 |
  | 流程文件名 `research` | 不显示 | 由标题生成，照工作区 id 的规矩 |
  | 阶段主文件 `ledger.tsv` | 账本 | 主文件表的中文名 |
  | 执行者种类 `needs_executor` | 不显示 | — |

  唯一例外是文件镜头：路径在那里是内容，`font-mono` 也只许出现在那里与代码块。
- **能力三层对三种动作。** 名直接显示；一行（`brief`）hover；详情（职责 / 边界 / 输入 / 产出 / 终止条件 + 参数）点击跳转。一个阶段挂再多能力也只是名字的清单——节点上的小片、配置板的行、陈列页的列都是名字。
- **机器判。** `src/copy.test.ts` 扫源码（去掉注释）：命中禁用词即失败，`font-mono` 出了文件镜头、对话里的工具行、需求 diff、产出目录的文件清单即失败；后端 `tests/test_chat_server.py` 走一遍页面读的端点，凡 id / name / slug 必伴随 title / label（阶段的 name 本身是中文）。

## Motion

只回应动作：模块填上、作业跑完、键按下、助理逐字说话（流式）。150–250ms，ease-out。无页面加载编排，不给每张卡加 hover 阴影。**换地方没有中间态**（主人 2026-09-23：每切一页闪一下刺眼）：每种数据上次拿到的那份按名字记着（`lib/lastSeen`），回来先摆上次的再后台重拉，不闪骨架屏；全站的十张图页面一起来就预热（`lib/pictures`），铺上去直接就在，只有第一次到的图才 300ms 淡入；第一次进一个项目页眉与底图先到位、字的地方放骨架，不让整块先空一下。每次打开都从首页（项目墙）进，不记上次在哪。`prefers-reduced-motion` 下全部退化为直接出现：CSS 动画归零，JS 驱动的（逐字浮现、电光边、闪字、火花、胶囊鼓圆、提示语轮换）在组件里按 `useReducedMotion` 换成静态。视频背景只在门口那一屏：循环无缝、无声、`playsInline`，首帧就是海报所以起播不跳；减少动效或省流量（`saveData`）不拉视频只给海报，加载失败也停在海报。

## 窄屏

64rem 以下：工作区页与编辑台的对话收进右侧抽屉（右下角那枚「打开对话」拉出来），地方栏收进页眉左端的玻璃标记（点开一张清单：首页 / 编辑台 / 设置三行），页眉只留标题。首页的项目墙一列到底，项目页那一列本来就是 44rem，原样；门口那一屏只剩问句与输入框，视频照铺。

CDN：`https://media.zephyrxiang.com/ai4science/v1/`（腾讯云 COS + CDN，`Cache-Control: immutable`，内容变了换文件名不复用；referer 白名单含 localhost）。来源站的文件先下到本机、处理好、再推桶——境外源站当背景加载不出来等于没有。
