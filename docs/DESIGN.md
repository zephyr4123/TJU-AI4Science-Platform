# Design

视觉系统（2026-09-17 第三版起，外层 [#64](https://github.com/zephyr4123/TJU-AI4Science/issues/64)）。第一版仪表盘被否，第二版一页纸白底琥珀；现在的样子：冷白纸面、五个当信息用的颜色、宋体只给标题、风景当底、一个抬起的面，安静。

## Scene

给不写代码的研究者用的科研工作台。页面头号任务一句话：现在做到哪一步、在等谁、数字可不可信。视觉从这些真实的东西长——账本、基线、统计门、验证、需求的确认与产出的确认两处人的动作——不从 SaaS 模板长，也不套「纸墨」这类隐喻（主人 2026-09-19：隐喻是另一种 AI 味）。

## Color strategy

五个颜色都是信息，不是装饰。一眼分得出三种状态：助理在跑（靛）、等你（琥珀）、可信（铜绿）。

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--background` 纸 | `#F5F6F8` | `#171A20` | 工作面，冷白不是奶油色 |
| `--foreground` 墨 | `#1C2230` | `#E6E8EE` | 正文与标题，蓝黑墨水 |
| `--primary` 靛 | `#2F4BC9` | `#8FA3F5` | 助理在动、可点的东西、流程线、发送键 |
| `--ok` 铜绿 | `#1F7A6D` | `#5FC2B0` | 只给「验证通过、可信」 |
| `--wait` 琥珀 | `#B8741A` | `#E2A751` | 只给「待确认」：需求、流程里断点前的产出 |
| `--muted-foreground` | `#5B6270` | `#9AA1AE` | 次要文字（对纸面 ≥ 4.5:1） |
| `--card` | `#FFFFFF` | `#1E222A` | 抬起的面（对话板、文件镜头的内容区、设置板）、输入框 |

深色跟系统偏好，设置 → 外观三档可拨（记在本机 localStorage，`lib/theme.ts` 写 `<html data-theme>`，画布类组件经 `themechange` 重读 tokens）。`--bad` 只给出错，配文字与图标一起出现，不单靠颜色。

## Typography

两族，分工清楚：

- **思源宋体（Noto Serif SC Variable）**：只给页面上的标题——欢迎语与项目名（`chat/Welcome`、项目页）、看板上阶段与产出的标题（`.t-step`）、Markdown 里的标题、页眉名字。助理的回复按普通 Markdown 排，不拎结论（主人：别限得这么死，让它自己用 Markdown 发挥）。期刊味，和实验记录本对味。
- **IBM Plex Sans Variable + 系统中文**：正文、界面、数字（全局 `tabular-nums`）。命令与文件名用 IBM Plex Mono，因为它们真是命令。

| 角色 | 尺寸 / 行高 / 字重 |
|---|---|
| 欢迎语 | 1.75rem / 1.25 / 600 宋体（`chat/Welcome.tsx`） |
| 步骤标题 `.t-step` | 1rem / 1.4 / 600 宋体 |
| 正文 `.t-body` | 0.9375rem / 1.65 / 400，行长 ≤ 68ch |
| 标签 `.t-label` | 0.8125rem / 1.4，`--muted-foreground` |

不做的：全大写小标签、中点串元信息（写成一句话）、给标题里某个词单独上色。

## Layout

最左一条**地方栏**，只剩三个键（外层 [#136](https://github.com/zephyr4123/TJU-AI4Science/issues/136)，主人 2026-09-22：侧边栏列项目很鸡肋）：宽屏常驻 4.5rem——顶上一枚玻璃标记，底下「首页」「编辑台」两个键是两个平行的世界（纲领 P-15 P-16），最底下「设置」（P-25，归人、全局一份，旁一个琥珀点，有一项自检没过才亮）；每个键都带字（主人：没字用户不知道是啥）。地方栏与页眉同一种磨砂（底图糊开 + 纱幕），连成一个 L 形框；两者之间不画实线，地方栏右边、页眉底边各是一道两头渐隐的双层细线（一深一亮，`index.css` 的 `edge-r` `edge-b`），左上角不交成「T」；开着的键靛色上亮下深、顶边一道高光、底下一团淡靛光，关着的半透明软底、悬停变实、按下轻轻缩一下；页眉「‹ 上一级」与标题之间一道淡斜杠（外层 [#253](https://github.com/zephyr4123/TJU-AI4Science/issues/253)，主人 2026-10-06：分割线太普通、看着劣质）。项目不在栏上列，首页就是项目清单。窄屏收进页眉左端的玻璃标记，点开一张清单，同样三行。页眉只属于当前地方：项目页与工作区页底下铺全站那张底图糊成一抹颜色，工作区页写「‹ 项目名  工作区 ▾」；首页与门口那一屏宽屏没有页眉（画面铺满），窄屏留一条放入口。页面先认项目（一个项目一位助理，工作区是它的工位）：

- **首页 = 项目清单**（外层 [#249](https://github.com/zephyr4123/TJU-AI4Science/issues/249)，主人 2026-10-05：三列格子名字高低不齐；封面图与项目无关，看着难受——不放图，只靠字与材质）：整张清单是一块玻璃（与产出悬浮窗同一种，`components/glass.ts`），底下垫两团静态的极光——靛在左上、青在右下（`--aurora-1` `--aurora-2`，深浅两套，只垫底与描边、不表示状态），边上一圈从靛渐到青的细线（主人：纯白太素，做点渐变、炫一些但不多）；一行一个项目，新的在前：宋体项目名（最多两行）、目标一句，右边三列事实「运行中 K」「N 个工作区」「创建于几月几日」，列宽固定、右对齐、上下对齐；行与行之间一根缩进的细线。鼠标在哪行，那行跟着一团淡靛光（只在鼠标动时写 CSS 变量，不起帧循环），事实往左让、右端出来一枚「…」，里面只有删除项目（外层 [#250](https://github.com/zephyr4123/TJU-AI4Science/issues/250)，主人：非得点进项目才能删不对；按住一秒，连工作区、对话、机器上的镜像一起删；触屏与窄屏常显、给它留位置），键盘聚焦同样；鼠标停到那一行就先去取那个项目的一整份（`project/prefetch.ts`），点下去项目页直接摆出来、不闪骨架。标题「项目」旁是项目数（同一基线）；右上角搜索框与「新建项目」：搜索按名字与目标筛，空白分开的几个词都要对上，搜中的字垫一层淡靛，搜不到写「名字和目标里都没有「…」」，Esc 清空（`home/derive.ts`）。一个项目都没有：一句「还没有项目」加一枚玻璃键「新建项目」（与「打开对话」同一种 SpecularButton）。
- **门口那一屏**（起项目）：一句「要研究什么？」、一只和对话输入框同款的玻璃输入框，写下课题回车即建，第二行「目标，可不填」进 project.md 标题下面那段；文件夹名从标题里推（拉丁词小写连字符相连，没有就按日期，重名加 -2），是内部 id，不显示也不让人填（外层 [#109](https://github.com/zephyr4123/TJU-AI4Science/issues/109)）；底下铺一段循环视频：浅色云雾、深色光线汇聚，纱幕压到字能读。第一个工作区不在这里起——进了项目跟助理说，它去开；或按项目页的「新建」。
- **项目页**（主人 2026-09-22：对话入口从右边的板搬到正中间，一个项目只有一位助理，入口顺理成章只有一个，像 Claude 的首页）：底下铺全站那张底图（mist 纱幕），正中一列 44rem——宋体大项目名、目标一句、一只玻璃输入框（placeholder「要做什么？」，上面「助理 / 模型 / 思考」三枚片），打的第一句话就开始对话：输入框**竖直下沉到底**（motion 的 layoutId，两边的盒子都紧贴玻璃框、同宽 44rem——盒子比玻璃框宽会斜着走；减少动效直接出现），正文淡入接在上面，这一轮从按下回车起就在屏上（主人：不要闪一下再切过去；`chat/useConversation`：先开一段再发，跑完先重读落盘的再撤屏上的，按轮次去重），页眉「‹ 项目名」+ 对话标题 + 花费 + 「对话 · N」；输入框底下是**工作区清单**，一行一个（shadcn item 的形状）：reactbits StatusMark 改装的状态符（空心虚线环 / 转圈 / 勾 / 叉）、宋体名字、两句小字（「流程「文献调研」1 / 1 步」「共产出 6 次」——带上「流程」二字与书名号，主人 2026-10-05：只写「文献调研 1 / 1」看不出它是流程）、右端状态一个词（需求未确认 琥珀 / 运行中 靛 / 待确认 琥珀 / 进行中 靛 / 完成 铜绿 / 尚未选定流程 素 / 流程文件有误 红；`project/derive.ts`），点一行进工作区页；「新建」在清单那一行，点了才在清单顶上展开表单（课题一句、学科片、回车即建，建好直接进那个工作区），加完收回去；最底下「对话 · N」是过去对话的抽屉，挑一段也切成整屏的对话。左上角「‹ 首页」回首页（外层 #250：先前宽屏只能点地方栏），右上角「…」里是删除项目（与首页那枚同一件，`project/ProjectMenu.tsx`）。

## 文案

词表只有一份，在外层纲领 workflow §5 界面适配（P-21，外层 [#112](https://github.com/zephyr4123/TJU-AI4Science/issues/112)），这里不抄：一个概念一个词，没进词表的词不上屏。页面上的字按四条走：

- **标签是名词，按钮是动词，句子只进解释层。** 标签、列名、状态词、节点名两到四字名词；按钮两字动词（保存、另存、排列、确认）；解释性文字只在 hover、空态、展开层，一句为限，工程语言不口语（不写「签了」「没成」「在跑」「干什么」这类）。
- **机器的名字不上屏。** 翻译在后端做，前端只显示后端给的中文：

  | 机器的名字 | 页面上 | 来源 |
  |---|---|---|
  | 能力名 `auto-research` | AutoResearch | 描述符 `title`；skill 的名就是它的名字（pdf） |
  | 参数名 `max_iters` | 本次轮数 | 描述符参数 `label`，`help` 做 hover |
  | 产出 id `design/1` | 设计 · 1 | 阶段名 + 编号 |
  | 流程文件名 `research` | 不显示 | 由平台起（P-15）：派生的 `<家族名>-<序号>`，从零拼的按标题里的英文词（撞了加 `-b`、`-c`） |
  | 阶段主文件 `ledger.tsv` | 账本 | 主文件表的中文名 |
  | 执行者种类 `needs_executor` | 不显示 | — |

  唯一例外是内容本身是命令或路径的地方：文件镜头、对话里的工具行、需求的行级 diff，`font-mono` 只许出现在这三处（`copy.test.ts` 的白名单）。
- **能力三层对三种动作。** 名直接显示；一行（`brief`）hover；详情（职责 / 边界 / 输入 / 产出 / 终止条件 + 参数）点击跳转。一个阶段挂再多能力也只是名字的清单——节点上的小片、配置板的行、陈列页的列都是名字。
- **机器判。** `src/copy.test.ts` 扫源码（去掉注释）：命中禁用词即失败，`font-mono` 出了文件镜头、对话里的工具行、需求 diff 即失败；后端 `tests/test_chat_server.py` 走一遍页面读的端点，凡 id / name / slug 必伴随 title / label（阶段的 name 本身是中文）。

## Motion

只回应动作：模块填上、作业跑完、键按下、助理逐字说话（流式）。150–250ms，ease-out。无页面加载编排，不给每张卡加 hover 阴影。进度面板的动只说状态（外层 #242）：运行中的方块一圈靛光呼吸（2.4 s）、通向它的连线虚线顺着方向流、新来的格子从小到大浮出（420 ms，一批错开、最多拉 700 ms；打开一次跑完的不演）、文献在几堆之间滑过去（550 ms，motion 的 layoutId）、正在筛的虚格与在读的那几枚一闪一闪。**换地方没有中间态**（主人 2026-09-23：每切一页闪一下刺眼）：每种数据上次拿到的那份按名字记着（`lib/lastSeen`），回来先摆上次的再后台重拉，不闪骨架屏；全站那张底图页面一起来就预热（`lib/pictures`），铺上去直接就在，只有第一次到的图才 300ms 淡入；第一次进一个项目页眉与底图先到位、字的地方放骨架，不让整块先空一下。每次打开都从首页（项目清单）进，不记上次在哪；进了之后换地方写进浏览器历史，后退 / 前进、鼠标侧键、触控板回扫都回得去，网址不变、刷新照旧回首页（外层 #250）。`prefers-reduced-motion` 下全部退化为直接出现：CSS 动画归零，JS 驱动的（逐字浮现、闪字、火花、胶囊鼓圆、扫光）在组件里按 `useReducedMotion` 换成静态。视频背景只在门口那一屏：循环无缝、无声、`playsInline`，首帧就是海报所以起播不跳；减少动效或省流量（`saveData`）不拉视频只给海报，加载失败也停在海报。
