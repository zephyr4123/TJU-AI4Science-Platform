# Design

视觉系统（2026-09-17 第三版，外层 [#64](https://github.com/zephyr4123/TJU-AI4Science/issues/64)）。第一版仪表盘被否，第二版一页纸白底琥珀，这一版给页面一个性格：实验记录本。

## Scene

给不写代码的研究者用的科研工作台。页面头号任务一句话：现在做到哪一步、在等谁、数字可不可信。世界观来自实验记录本和评分脚本——账本、基线、统计门、验证、需求的确认与产出的确认两处人的动作。视觉从这儿长，不从 SaaS 模板长。

## Color strategy

五个颜色都是信息，不是装饰。一眼分得出三种状态：助理在跑（靛）、等你（琥珀）、可信（铜绿）。

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--background` 纸 | `#F5F6F8` | `#171A20` | 工作面，冷白不是奶油色 |
| `--foreground` 墨 | `#1C2230` | `#E6E8EE` | 正文与标题，蓝黑墨水 |
| `--primary` 靛 | `#2F4BC9` | `#8FA3F5` | 助理在动、可点的东西、流程线、发送键 |
| `--ok` 铜绿 | `#1F7A6D` | `#5FC2B0` | 只给「验证通过、可信」 |
| `--wait` 琥珀 | `#B8741A` | `#E2A751` | 只给「待确认」：需求、流里断点前的产出 |
| `--muted-foreground` | `#5B6270` | `#9AA1AE` | 次要文字（对纸面 ≥ 4.5:1） |
| `--card` | `#FFFFFF` | `#1E222A` | 顶栏、看板上填实的卡、输入框 |

深色跟系统偏好，页眉右边的开关可以拨（记在本机 localStorage，`lib/theme.ts` 写 `<html data-theme>`，画布类组件经 `themechange` 重读 tokens）。`--bad` 只给出错，配文字与图标一起出现，不单靠颜色。

## Typography

两族，分工清楚：

- **思源宋体（Noto Serif SC Variable）**：只给页面上的一句话标题（`.t-lede`：欢迎语、需求的课题名）、看板上阶段与产出的标题（`.t-step`）、Markdown 里的标题、顶栏名字。助理的回复按普通 Markdown 排，不拎结论（主人：别限得这么死，让它自己用 Markdown 发挥）。期刊味，和实验记录本对味。
- **IBM Plex Sans Variable + 系统中文**：正文、界面、数字（全局 `tabular-nums`）。命令与文件名用 IBM Plex Mono，因为它们真是命令。

| 角色 | 尺寸 / 行高 / 字重 |
|---|---|
| 一句话标题 `.t-lede` | 1.25rem / 1.45 / 600 宋体 |
| 步骤标题 `.t-step` | 1rem / 1.4 / 600 宋体 |
| 大数字 `.t-big` | 1.75rem / 1 / 500，等宽数字 |
| 正文 `.t-body` | 0.9375rem / 1.65 / 400，行长 ≤ 68ch |
| 标签 `.t-label` | 0.8125rem / 1.4，`--muted-foreground` |

不做的：全大写小标签、中点串元信息（写成一句话）、给标题里某个词单独上色。

## Layout

最左一条**地方栏**，先选世界再选世界里的东西（宽屏常驻 4.5rem：顶上一枚玻璃标记，最底下两块是双向开关——主页面 / 编辑台，两个平行的世界，放底下不抢视觉；开关上面那段只属于当前世界：主页面世界里是一块块封面，靠近放大、点即切换，末尾「新建」；每段都带字：列表顶上「工作区」，块底下「新建」「主页面」「编辑台」（主人：没字用户不知道是啥）；编辑台世界里这段收掉，那里没有可切的东西，从结构上就切不了工作区。编辑台是全局一个库、有自己的对话，不跟着工作区换；窄屏收进页眉左端的玻璃标记，点开是一张清单，同样先两个世界再列内容，[#79](https://github.com/zephyr4123/TJU-AI4Science/issues/79)）。页眉只属于当前地方：工作区的标题 + 走到哪，底下铺封面糊成一抹颜色，换工作区就换色；编辑台是库的横幅、注一句「不分工作区」；门口那一屏宽屏没有页眉（画面铺满），窄屏留一条放入口。下面两块看板以可写目录划界（[#58](https://github.com/zephyr4123/TJU-AI4Science/issues/58)）；页面先认工作区（[#70](https://github.com/zephyr4123/TJU-AI4Science/issues/70)）：

- **主页面**（改实例）：没有工作区（或点了「新建」）时是门口那一屏：一句「要解决什么？」、一只和对话输入框同款的玻璃输入框，写下课题回车即建；底下一行学科片（「学科」标签在前，通用在前、按学科加，小字「需求提纲按学科起草」）；文件夹名从标题里推（拉丁词小写连字符相连，没有就按日期，重名加 -2），是内部 id，不显示也不让人填（外层 [#109](https://github.com/zephyr4123/TJU-AI4Science/issues/109)）；右边一张封面卡随名字换（封面本来就按名字挑，名字一变封面就换）、副标题是所选学科、跟着鼠标歪；底下铺一段循环视频：浅色云雾、深色光线汇聚，纱幕压到字能读。有了工作区，**看板铺满**、对话是右边一块悬在雾景上的板（30rem，四周留 12px、圆角 2xl、长而软的投影 + 一圈 6% 的 ring，和文件镜头的内容面同一种材料，板与看板之间露出的雾景就是分隔——主人 2026-09-19：`border-l` 一刀切出来的全高一列像拼上去的；可收，收起后右下角一枚圆形入口），看板按 `requirement.lock` 在不在分两个状态（纲领 P-19，外层 [#104](https://github.com/zephyr4123/TJU-AI4Science/issues/104) [#107](https://github.com/zephyr4123/TJU-AI4Science/issues/107)）：
  - **没确认**：需求文档就是页面。宋体课题名、右边「需求 · 未确认 · 填了几节」，模板开头那段说明淡字，下面按二级标题两列一格一节（填了的是 SpotlightCard，正文 markdown；「待填」的虚线框灰字），最底下一颗「确认」（StarBorder，署名记在本机）。页面只渲染不编辑：改需求跟右边的助理说，它改文件，页面每轮对话结束重读。
  - **确认了**：需求收成顶部一条（课题名、v 几、谁、何时；点开侧滑看全文），助理又改了这条变琥珀、写「N 行改动 · 待确认」，侧滑里是上一版对现在的行级 diff（加的绿、删的红）与「确认」下一版。下面**一条流一张表**（主人 2026-09-19：七个格子加一条流两套东西叠着看不明白，大胆做减法；语言用正式直白的词，不用「签」「没成」这类口语）：题头是流的标题 + mono 名字，右上角一句话说在等谁（下一步：实验 · 助理 / 待确认：设计 1 / 运行中：实验 2 / 完成 / 流文件有误）。横向是流经过的阶段，有什么阶段就几列（11.5rem 一列，横向可滚）：列头阶段图标 + 宋体阶段名，底下一行小字是这一步的能力的人话（点名的，或这个阶段能用的；没有就「无内置能力」）；纵向是这一列跑过的每一次产出，一张一个：mono 编号 + 一个词（运行中 靛 / 失败 红 / 待确认 琥珀 / 已确认 铜绿 / 完成 素）。下一步那一列靛色边框、里面一张虚线「下一步」；作业在跑是「运行中」带呼吸点；没到的列虚线淡、占一张空框。断点是两列之间一道竖线：签名的笔（待确认琥珀实心）或 ✓（已确认铜绿），没到是灰；线底下两三个字（确认事项的第一段，最多六个字），全句悬停。不在任何流里的产出只在最底下一行「其它」；还没取流只有一句「尚未选定流」。产出点开**侧滑**：记录（来源、状态、输入、流的第几步、需求第几版、时间、参数）、目录里的文件（小文本直接渲染，二进制只给名字）、这次产出的作业、确认（流在这儿等你确认就带一句提示；确认过的显示谁何时、目录改了就写「之后有改动」）。有作业在跑时每 10 秒重拉一次，别的对话起的作业跑完这边才看得见。**文件镜头**（主人 2026-09-19：每个工作区要能看见盘上实际的目录，之后每个工作区单独 Git 管理，看不见代码不 make sense；不是地方栏上第三个地方，是同一个工作区的另一个镜头，外层 [#111](https://github.com/zephyr4123/TJU-AI4Science/issues/111)）：页眉右侧一枚「看板 / 文件」分段开关，对话列两边都在。第二版（主人：第一版两个平面一根竖线一条横线，全是平方块没有层次；「纸墨」隐喻否掉——另一种 AI 味）：**去框，只留一个面**。左边 17rem 的树不要底色不要边框，直接印在雾景上，它是索引不是面板；右边内容区是一块抬起的板（`bg-card`、长而软的投影、圆角 2xl、一圈 6% 的 ring，四周留 12px），两者之间不用线分；对话那块板在它右边，中间一条雾景。树是大纲不是文件管理器：每一级一根浅灰缩进导线（不上色——主人：蓝线太丑）；阶段目录写宋体阶段名 + 阶段图标，行距统一不分组（主人：分组的空行看着像没对齐）；产出那一层 mono 编号，状态词右对齐成一列（运行中 靛带呼吸点 / 失败 红 / 已确认 铜绿带 ✓ / 完成 素），被引用或已确认的再一把小锁；选中行是左缘 2px 靛条 + 加粗，不是填充色块；`.ai4sci/` 灰显垫底；根一层按工作区骨架排；产出那一层第一下点正文是选中看记录并展开，已选中再点就开合，折角单独可点；一层一层懒加载，子目录加载不画骨架，空目录一行「空」。内容区头部是「位置」：面包屑写平台语义（⚗ 设计 › 1 · 已确认 › harness，每段可点回上一级），底下文件名 mono 大字 + 大小与行数，右侧「在看板打开」（属于产出的文件）；没有「下载」——文件本来就在盘上（主人）。正文按种类：代码高亮（highlight.js 只装 python / yaml / json / bash / ini 五种，配色只用站内三色：关键字靛、字符串铜绿、数字琥珀、注释灰）、行号在一根细竖线左侧钉住、不折行横向滚；markdown 排版；csv / tsv 成表（数字列右对齐等宽，最多 200 行）；图片居中放在中性底上；超过 200 KB 只显示开头、二进制只说一句不显示。选中产出那一层，右边是位置 + 侧滑那份记录与确认。进来先看 `requirement.md`；从看板侧滑「打开目录」过来就展开到那次产出并选中。只看不改；Git 状态先不画。画面全是风景（主人：别用玻璃瓶、实验室味的图）：门口那一屏的视频与欢迎屏的雾山放胆，对话与看板底下的只是氛围（`.veil-mist` 压七成）。
- **对话抽屉**：入口是对话列顶上一枚带字的圆角按钮「对话 · N」（hover 扫过一道淡靛光）；顶上是这个工作区的封面（编辑台是库的横幅），字站在脚下压成纸色的那一段；清单逐条浮现，当前那段的气泡图标填实。
- **编辑台**（改库，[#100](https://github.com/zephyr4123/TJU-AI4Science/issues/100)）：一整张画布铺满（React Flow），底下压一层风景（晨光山脊线，mist 纱幕，与主页面的看板同一做法），点阵铺在风景上。不是表单：左上角一根**阶段梯**——七个研究阶段按顺序竖排成方块（大图标、宋体名），底下一块断点（琥珀；是发布、验收还是别的，拖进去在配置里选）；梯子右边是**题头**——一块玻璃板（GlassSurface，与门口的输入框同款），宋体大标题、mono 名字、一行说明直接写在板上，没有框没有线，聚焦整块板亮一圈；右上角「库 N」弹层与圆角「保存」，名字与库里重了才出现「覆盖同名」的开关。造流助理不占一列：右下角一枚圆形玻璃入口（reactbits Magnet 磁吸 + ClickSpark），点开在角上长出一扇悬浮的对话窗（GlassSurface 壳，motion 从右下角缩放长出来；窗里就是对话那一列：抽屉、对话、输入框，右上角一枚关闭），再点收起——画布是主角，对话是辅助。梯子上的块拖进画布落在哪条边上就插在哪，点一下加到末尾。节点是一张卡：阶段卡（SpotlightCard 改装：22px 图标、宋体阶段名、点名的能力做靛色小片，没点名写「不限能力」，右下角一枚淡的宋体大序号——序号是文件里真实的第几项）、断点卡（琥珀底：图标 + 确认事项两行，发布盖章、验收签名）；边是折线带箭头，只表示顺序。位置：没摆过的按顺序自动排、一行放不下换行；拖一个节点松手它就留在那儿（不弹回），顺序按阅读顺序重算（先上后下、同一行先左后右），边跟着顺序画；人摆过坐标就存进文件的 `layout` 块，右上角多一枚「整理」回到自动排。选中一个节点右上角浮出配置：阶段 → 这个阶段的能力逐个勾选、勾上就按描述符给参数输入框（布尔是 SquishSwitch，数字 / 字符串是输入框，空着就是缺省值；每次调用时才定的参数如 run_id 不给）、箭头展开五栏；断点 → 三选一：发布、验收（框架守着的两个，各有记录）、其它（写一句确认事项）。检查结果在左下角：通过就说经过哪几个阶段，有问题一条一条列、并在节点上打红点（悬停看句子）；提醒琥珀色。窄屏配置改成右侧抽屉。

对齐：全部左对齐；数字右对齐成列。

## Components

shadcn（radix-nova 预设）作基础件；编辑台的画布是 React Flow（`@xyflow/react`，MIT，Dify 同款引擎），点阵与边的颜色走 tokens；它自带的缩放按钮与署名不要（缩放靠滚轮 / 双指，加减项自动取景）。reactbits 只用在承担信息的地方，从 registry 捞来改装、走 tokens：Dock（地方栏：横改竖、块是真按钮、名字靠右提示、减少动效不放大）、SpotlightCard（需求的节、编辑台的阶段卡）、StarBorder（确认需求、给产出签字两处，全页只有它们有这种质感）、ShinyText（作业跑着时的状态字）、GlassSurface（输入框的壳、编辑台的题头与悬浮对话窗的壳，跟 `data-theme`）、FoldText（面板的名字像折纸展开，gsap 换成 motion）、TiltedCard（门口那张封面卡，换名字换图）、GlareHover（对话抽屉的入口按钮，改成真按钮）、GlassIcon（顶栏那枚标记，GlassIcons 只留一枚）、AnimatedList（工作区清单与对话清单逐条浮现）、SquishSwitch（页眉的深浅色开关：滑块拖得越快拉得越长，颜色走 tokens、做小；编辑台里布尔参数也用它）、Magnet（编辑台右下角的对话入口：指针靠近被轻轻吸过去，减少动效与触屏不动）、GlideSelect（输入框上「模型」「思考」两枚下拉片：菜单从片的一角弹出、高亮在行间滑动，改装成挂在 body 上定位——玻璃壳 overflow-hidden 会切菜单——片上带前缀字、图标换 Phosphor、颜色走 tokens）。`components/Band` 是自家的：一张图 + 一层纱幕，顶栏（wash，糊成颜色）、抽屉与库（foot，脚下压纸色）都用它；`components/Scene` 也是自家的：铺满整块面板的画面，欢迎屏（side，左边压纸色给字站）、对话正文与看板（mist，压七成只剩氛围）用它。图标 Phosphor（regular；看板开着那颗用 fill），全站一套，`components.json` 的 `iconLibrary` 也是它，shadcn 再生成的件不会带回 lucide。

## Motion

只回应动作：模块填上、作业跑完、键按下、助理逐字说话（流式）。150–250ms，ease-out。无页面加载编排，不给每张卡加 hover 阴影。`prefers-reduced-motion` 下全部退化为直接出现：CSS 动画归零，JS 驱动的（逐字浮现、电光边、闪字、火花、胶囊鼓圆、提示语轮换）在组件里按 `useReducedMotion` 换成静态。视频背景只在门口那一屏：循环无缝、无声、`playsInline`，首帧就是海报所以起播不跳；减少动效或省流量（`saveData`）不拉视频只给海报，加载失败也停在海报。

## 窄屏

64rem 以下：对话收进右侧抽屉（看板右下角那枚圆形入口拉出来），编辑台改成上对话下库，地方栏收进页眉左端的玻璃标记（点开一张清单：先「工作区 / 编辑台」两个世界，工作区世界里再列工作区与「新建」），页眉只留标题。门口那一屏只剩问句与输入框，封面卡不显，视频照铺。

## 素材

除了图标用 SVG 内联，图片与视频一律走自己 CDN 的 URL，仓里不放二进制（纲领 P-17，外层 [#75](https://github.com/zephyr4123/TJU-AI4Science/issues/75)）。URL 只写在 `ui/web/src/assets.ts`；`make ui-check` 查 `git ls-files ui/` 里没有 png / jpg / mp4。

CDN：`https://media.zephyrxiang.com/ai4science/v1/`（腾讯云 COS + CDN，`Cache-Control: immutable`，内容变了换文件名不复用；referer 白名单含 localhost）。来源站的文件先下到本机、处理好、再推桶——境外源站当背景加载不出来等于没有。

| 用途 | 文件 | 来源 | 作者 | 许可 | 处理 |
