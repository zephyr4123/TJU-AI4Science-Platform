# Product

## Register

product

## Users

非工程师、非本专业的研究者：化学、生物、物理系的博士生与课题组成员，手里有一段能跑的代码和一个想压低或抬高的数，不会也不想学命令行。他们在白天的实验室或办公室用笔记本打开这个页面，一次坐下来做一件事：把想做的实验说清楚并发布、或回来看结果能不能用。频率是每周几次，不是全天挂着。第二类用户是项目负责人（主人）与他带的工程师，他们会翻细节，但不是页面的默认读者。

## Product Purpose

把"跑一轮诚实的对照实验"的门槛降到会说话就行。人只在两处出现：发布需求、验收结果；中间的接任务、跑基线、改代码、过统计门、写分析、验证数字全部由协调 agent 按框架的按钮完成，框架零模型调用、每一步留痕。成功的样子：一个化学系的博士生不看文档就能发布第一个需求，回来后三十秒内知道"比原来好了多少、可不可信、能不能拿去用"，并且敢在验收键上署名。

## Brand Personality

诚实、安静、可靠。像一位不多话的实验室助理：先说结论，用你听得懂的话，数字给三个不给三十个，不确定的地方直说"没验证"。三个词：坦白、克制、有分寸。情绪目标是"放心"，不是"惊艳"。

## Anti-references

- 后台管理面板：一屏三十个字段、表格套表格、状态码原样显示（第一版就是这样，主人的评价是"奇丑无比"）。
- SaaS 仪表盘套路：大数字卡片配渐变、图标标题文字的等宽卡片网格、每段一个小字母眉题。
- AI 产品的炫技：满屏光效、打字机动画、玻璃拟态。动效只在承担信息时出现。
- 工程师黑话直出：inner_k、accept_sigma、σ、gate、harness_sha、executor_failed、commit 哈希，一律不出现在正文。

## Design Principles

- **一页纸报告，不是仪表盘**：每张看板像助理写给你的一页纸——先一句话结论，再三个大数字，再几段人话，键在文末。回答不了"这页替用户回答哪句话"的字段折进细节或不放。
- **先说人话，再给字段**：状态、判决、失败类型一律翻译成句子；原始命令与技术值放在展开层，工程师翻得到，研究者不必看。
- **诚实优先于好看**：没跑验证就写"没验证"，验收后 best 变了就说"要再看一遍"，成本与轮数如实显示；不用视觉手段暗示不存在的把握。
- **人只按两颗键**：发布与验收是页面上仅有的两个"只有人能按"的动作，它们要一眼可见、署名可查、按下去有回响；其余都是看。
- **对话是入口，看板是旁证**：对话为主、看板在右；看板显示的永远是磁盘上真实的文件状态，不是页面自己的猜测。
- **说人话，不用内部词**（2026-09-17 主人实测后定，外层 [#69](https://github.com/zephyr4123/TJU-AI4Science/issues/69)）：「按钮」「能力单元」「工具调用」这些是平台内部的词，研究者看不懂。页面上每条命令翻成一句直白话——查了有哪些能力、跑了基线、写了分析；被拒的命令说清为什么，不贴英文原文。同样的要求写进指南前言，agent 对研究者说话也照办。
- **看板随工作流变，不写死流程**（2026-09-17 拍板，外层 [#58](https://github.com/zephyr4123/TJU-AI4Science/issues/58)）：主页面右侧是当前 run 正在照的那条工作流，一步一个模块，按文件顺序排。能力步骤显示它吐的文件（JSON 出几个大数字、markdown 出正文、目录出清单、PASS / FAIL 出勾叉；只有账本这类才配专门视图），键步骤就是那颗键，纯人步骤是一行待办。装 intake 才有需求对齐，装带写作的流才有写作模块。现在的三个页签是过渡形态。
- **两块看板，以能写哪儿划界**：编辑台改库（`workflows/`）：对话拼流、存文件，可选；主页面改实例（工作区里的 `task/` `flows/` `runs/`）：接流照跑，跑偏自己修，不立新流。需求对齐在主页面，是 intake 的前三步，配一张随对话填满的对齐清单。
- **一个工作区一份需求，两位助理各管一边**（2026-09-18 拍板，外层 [#70](https://github.com/zephyr4123/TJU-AI4Science/issues/70)）：页面先选工作区再说话，一个工作区里是这份需求的全部（任务包、取来改过的流、对话、run、作业）；课题组有几份需求就开几个。主页面的研究助理只能用流（从库里取、改参数、照着跑），编辑台另有一位造流助理只管把能力拼成流存进库。研究者看到的词是「工作区」「这条流」，不是目录名。

## Accessibility & Inclusion

WCAG AA：正文对比 ≥ 4.5:1，大字 ≥ 3:1；全部交互可键盘到达并有可见焦点；表格与列表有语义标记；动效尊重 `prefers-reduced-motion`（改为淡入或直接出现）；中文为主、术语保留英文原文时给中文解释；颜色不是唯一的状态信号（勾、叉、文字同时出现）。
