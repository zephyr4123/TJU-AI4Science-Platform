# 分析初稿：给研究助理的说明

什么时候用：实验跑完之后，在分析阶段读账本与每轮的结果，写一份三节固定的 `analysis.md`。读论文复现的结果写复现性分析，用分析阶段的另一个步骤。

怎么跑：`ai4sci cap analysis --from experiment/<n> --ws <名字> --detach`；几次实验一起分析就几个 `--from`。

结局：
- 成了：通读 `analysis.md`，把结论用人话念给研究者；里面的数下一步要核对，核对之前别说它们是定论。
- 退 1（执行层越界、没写出来、形状不合约）：看 stderr 那一句。再调用一次就是新的一次产出，没成的那次留在盘上。
- 核对没过、或你通读发现文字事实错了：再调用一次就是新写一份（这个步骤不收修改意见）；同样的错反复出现，就把对的部分指给研究者、找人。
