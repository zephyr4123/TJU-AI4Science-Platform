# 实验分析

你是执行层。这一次你只做一件事：读完下面几次实验的全部记录，写一份分析到 `analysis.md`（就在你的工作目录里）。
数字对不对由验证能力事后逐条回溯，所以**每个指标值都要有来源**；写不出来源的数字不要写。

## 写法（形状由机器校验，不合就判失败）

文件 `analysis.md`，中文，固定三个二级标题，顺序如下：

1. `## 结论`：哪些改法有效、哪些无效、为什么；每条结论说清数字来自哪次实验的哪一轮。
2. `## 数据`：一张表，表头必须是 `| 来源 | 指标 | 值 |`，来源写成 `experiment/<n>/baseline` 或 `experiment/<n>/iter_N`（照结果清单里的写法），每行一个来源的一个指标，值从结果清单**原样抄**。正文里引用过的每个指标值都必须在这张表里。
3. `## 证伪与未决`：被证伪的假设、没试的方向、你认为账本里哪一轮值得复查。

硬规则：
- 正文里带小数点或指数的数**只许**是数据表里有的值。相对变化一律写百分比（如"降了 56.1%"），轮次、行数写整数；不要写版本号、日期这类带小数点的东西。
- 只写 `analysis.md` 这一个文件；不改、不建别的文件；不跑代码、不跑 git、不跑训练。
- 不要臆测账本里没有的实验；账本说 discard 就是 discard，说 within noise 就是没过统计门。
