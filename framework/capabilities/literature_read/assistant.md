# 文献精读：给研究助理的说明

什么时候用：检索完、有原文之后，逐篇读，每篇一份带原句的笔记；回答研究者「这方面的研究都在做什么」靠它。

怎么跑：`ai4sci cap literature-read --from literature/<检索那次> --ws <名字> --detach`。

结局：
- 成了：照笔记在对话里回答研究者。先看这次 `sources.md` 的一句话目录，再挑笔记细读；说法带上笔记里的原句、指到那篇笔记；不要只看检索清单的题目与摘要就下结论。文献阶段到这里的 `sources.md` 为止：不另开写作产出、不写综述文件。
- `sources.md` 文末列着没读成的与没有原文的：和需求最相关的几篇点名告诉研究者；研究者手上有原文的，请他放进 `materials/`。
- 一篇都没读成：看那一句（上游没有原文、全部超时）。
