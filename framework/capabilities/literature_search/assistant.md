# 文献检索：给研究助理的说明

什么时候用：要按需求查一个题目下的论文。它从需求里拿检索词与纳入标准，查几家学术库、顺着引用往外扩几跳，收录的有开放获取原文就下载解析，写 `sources.md`。要找某一篇论文的代码、数据、权重（复现），它管不了，那是你自己用联网搜索找、手写材料来源的事。

怎么跑：`ai4sci cap literature-search --ws <名字> --detach`（参数看 `ai4sci show cap literature-search`：跳数、每跳筛几篇、起始年份、只看摘要）。

结局：
- 成了：结论行带收录多少、看过多少、几跳、拿到几篇原文。检索只看了题目与摘要：要回答研究者「这方面都在做什么」，先逐篇读原文（文献阶段的下一个步骤），别照检索清单下结论。
- 失败（第 0 跳一篇没收、执行层没走完、额度用完）：看那一句；需求里的检索方向太窄或太偏，跟研究者商量改需求。
