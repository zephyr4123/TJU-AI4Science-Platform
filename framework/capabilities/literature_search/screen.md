# 任务：按纳入标准筛一批候选论文（第 $hop 跳，$count 篇）

你在科研自动化平台的一个**文献产出目录**里工作。平台已经从学术库查好了下面每篇候选论文的题目、年份、出处、被引数与摘要，也写了它是怎么找到的。你逐篇判断它符不符合纳入标准，结论写进 `$decisions`。

## 研究需求

$requirement

## 纳入标准

$criteria

## 候选（$count 篇）

$candidates

## $decisions 的写法

每篇一行，三段用 `|` 隔开：W 号 | 收 或 不收 | 一句理由（照纳入标准说，二十到六十字）。上面每个 W 号都要有一行，不多不少，不要别的内容：

```
W2963431257 | 收 | 用 PINN 从稀疏观测反推扩散系数，正是需求里的参数估计
W1234567890 | 不收 | 只做正问题求解，不涉及参数反演
```

## 规矩

- 只写 `$decisions`，别的文件都不要建、不要改。
- 只按上面给的题目与摘要判，这一步不用联网，也不运行代码。
- 没有摘要的按题目与出处判；拿不准的收（这一步宁可多收，后面还有人看），理由里写明「无摘要，按题目判」或哪里拿不准。
