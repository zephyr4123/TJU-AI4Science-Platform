# 数字核对：给研究助理的说明

什么时候用：分析写完之后，在验证阶段零模型地核对：分析里的每个数都要能回溯到结果文件（复现性分析回溯到基线与论文值），账本与 git 对账。

怎么跑：`ai4sci cap verify --from analysis/<k> --from <那份分析读的实验或设计> --ws <名字>`，几秒就完，不用 `--detach`。

结局：
- 退 0：这份分析的数字全部可回溯。把结论与核对结果念给研究者，多半到了人验收的断点，研究者在页面上签 `verification/<k>`。**人确认，你不替人签**。
- 退 1：分析里有编的数、正文有表外的数，或账本对不上。读 `verification/<k>/report.json` 的 `details`：数字问题回分析阶段带上这些问题重写一份；账本问题停下来找人，不猜。
- 不是写错数、而是产物本身有问题（结果文件不合约、评分脚本被动过）：停下来找人。
